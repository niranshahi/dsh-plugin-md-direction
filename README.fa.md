# md-direction — پلاگینی برای دیپ‌سیک هارنس

[English](./README.md) · [فارسی](./README.fa.md)

یک باندل برای [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH)
که یک **کنترل سه‌حالتهٔ جهت متن** برای پاراگراف‌های مختلط فارسی/انگلیسی در
پنل گفتگوهای وب این محیط اضافه می‌کند.

**مالک و نگهدار:** N. Iranshahi — `niranshahi@gmail.com`

**همکار هوش مصنوعی:** پیاده‌سازی این پلاگین با همکاری یک دستیار برنامه‌نویس
هوشمند (ایجنت کدنویس GLM در DeepSeek Harness) به‌عنوان پشتیبان طراحی و
کدنویسی انجام شده است؛ روایت کامل در [LICENSE](./LICENSE) آمده و هر دو سهم
تحت لایسنس MIT منتشر می‌شود.

## چه کار می‌کند؟

وقتی پاسخ‌های گفتگو مخلوطی از پاراگراف فارسی و انگلیسی دارند، می‌توانید با یک
کلیک جهت خواندن کل مارک‌داونِ گفتگو را عوض کنید:

| حالت | کارکرد |
|-----|-------|
| `auto` (خودکار) | هر پاراگراف به نخستین شخصیت زبانی خودش لنگر می‌گیرد: پاراگراف فارسی راست‌چین، پاراگراف انگلیسی چپ‌چین. بهترین حالت برای محتوای مختلط. |
| `rtl` (راست‌چین) | همهٔ پاراگراف‌های مارک‌داون راست‌چین می‌شوند (`direction: rtl; text-align: right`)، بدون آنکه قطعه‌های انگلیسی درون‌شان (کد، لینک، عدد) خراب شوند. |
| `ltr` (چپ‌چین) | همهٔ پاراگراف‌ها چپ‌چین می‌شوند — ظاهر پیش‌فرضِ محیط. |

جزئیات مهم برای خوانایی:

- **قطعه‌های کد (`pre`) در هیچ حالتی جهت نمی‌گیرند** — همیشه LTR می‌مانند، پس کد و شمارهٔ خط‌ها سالم می‌مانند.
- **قطعه‌های کد درون‌خطی (`code`, `kbd`, `samp`) جدا از جهت بندِ اطراف، bidi-isolated می‌شوند** تا ترتیب حروف لاتین درون جملهٔ فارسی خراب نشود.
- **هندسهٔ فهرست‌ها و جدول‌ها با جهت انتخابی همسو می‌شود** (`padding-inline-start` و ترتیب ستون‌های جدول).
- **انتخاب شما ماندگار است** — بین بارلدها و بین سشن‌ها با `localStorage` (کلید `dsh.mdDirection`).
- استایل فقط به جریان گفتگو محدود است (`[data-conversation-scroll]`)؛ سایدبار، composer و صفحهٔ تنظیمات دست نمی‌خورند.

## کنترل‌ها کجا هستند؟

- یک **دکمهٔ سه‌حالته زیر composer** (اسلات `conversation.composer.dock`) — با هر کلیک بین «خودکار → راست‌چین → چپ‌چین» می‌چرخد.
- یک **ردیف با عنوان «جهت متن مارک‌داون» در `Settings → General`** (اسلات `settings.general.item`) — یک کنترل سه‌حالتهٔ صریح.

## نصب

این باندل یک پکیج ساده و مستقل است: بدون build، بدون وابستگی. React و همهٔ
ماژول‌های سمت مرورگر از طریق ماژول‌لودر DSH در زمان اجرا فراهم می‌شوند.

1. **پوشه را داشته باشید** — این ریپو را `git clone` کنید یا از صفحهٔ Releases
   بسته را دانلود و باز کنید. آن را در جایی **خارج از پروژه‌های کاری‌تان**
   بگذارید؛ مثلاً:

   | سیستم‌عامل | مسیر پیشنهادی |
   |-----------|----------------|
   | ویندوز | `C:\Users\<username>\dsh-plugins\md-direction` |
   | لینوکس | `~/dsh-plugins/md-direction` |
   | مک‌او‌اس | `~/dsh-plugins/md-direction` |

2. **در یک پروفایل DSH نصبش کنید** — در یک سشنِ DSH از ایجنت بخواهید باندل را
   با **مسیر مطلق پوشه** نصب کند؛ مثلاً:

   ```text
   install_bundle <مسیر مطلق به پوشهٔ md-direction>
   ```

   پروفایل فولدر را لینک می‌کند (کپی نمی‌کند). پاسخ `application: applied`
   یعنی ردیف روی پروفایل زنده است.

3. **یک بار صفحهٔ وب Harness را Reload کنید** — ماژول سمت مرورگر هنگام boot
   صفحه لود می‌شود؛ ریست‌کردن سادهٔ برنامه هم کافی است.

> **نکتهٔ اختلاف سیستم‌عامل‌ها:** پلاگین ذاتاً platform-agnostic است — فقط
> یک پچ YAML، یک ماژول جاوااسکریپتِ مرورگر، دو فایل locale JSON و یک آیکون
> SVG حمل می‌کند. هیچ چیزِ آن مخصوص ویندوز نیست؛ تنها تفاوت، جایی است که
> پوشه را نگه می‌دارید (جدول بالا). توزیع خودِ DeepSeek Harness بین
> سیستم‌عامل‌ها متفاوت است، اما سازوکار نصب (`plugin_manager` / bundle
> patch) همه‌جا یکسان است.

## حذف

با مدیریت‌کنندهٔ پلاگین پروفایل، باندل `@local/md-direction` را بردارید
(`remove_bundle`) و اگر پوشه را دیگر نمی‌خواهید حذفش کنید. انتخابِ شما (کدام
حالت فعال است) در `localStorage` ماشین خودتان ذخیره می‌شود، نه داخل پلاگین.

## ساختار فایل‌های ریپو

```
package.json          # manifestی dsh.bundle.patch + dsh.client، به‌همراه متادیتای author/license
cordis.patch.yml      # ردیفِ پلاگین را به ترکیب پروفایل می‌افزاید
index.js              # نیمهٔ Host (بدون کار؛ همهٔ رندرِ سمت Client است)
client.js             # ماژول مرورگر: UI کنترل، استایل‌شیت جهت، store حالت
locale/en.json        # متادیتای inventory باندل — انگلیسی
locale/fa.json        # متادیتای inventory باندل — فارسی
icon.svg              # آیکونِ اورجینال
LICENSE               # لایسنس MIT
README.md             # همین فایل (انگلیسی)
README.fa.md          # README فارسی
```

## چطور کار می‌کند (برای نگهدارنده‌ها)

- یک اتریبیوت روی `<html>` (`data-dsh-md-dir="auto" | "rtl" | "ltr"`) — داخل `ctx.effect` با cleanup سالم گذاشته و در unload برداشته می‌شود؛ همان الگویی که خودِ هارنس هم به کار می‌برد (`html[data-platform=darwin]` و `body[data-ds-dark-theme]`).
- یک استایل‌شیت با قاعده‌هایی به شکل
  `html[data-dsh-md-dir] [data-conversation-scroll] :is(p,h1..h6,ul,ol,li,blockquote,table,thead/tbody/tfoot,tr,td,th,summary,dt,dd,figcaption)`.
- یک store کوچک داخل ماژول (جاوااسکریپت ساده + React `useState`/`useEffect`) که هم دکمهٔ زیر composer و هم ردیف تنظیمات از آن می‌خوانند.
- دیکشنری‌های locale در خود `client.js` جاسازی شده‌اند (`en` مرجع، `fa` قرینه) و اگر سرویس locale در دسترس نباشد برچسب‌ها به انگلیسی برمی‌گردند.
- رنگ‌ها از طریق توکن‌های `--dsw-alias-*` به تم می‌چسبند؛ بیرون از آیکون هیچ رنگ صریحی استفاده نشده.

## ویرایش و انتشار نسخهٔ جدید

- تغییر `client.js` → باندل را دوباره نصب کنید (`remove_bundle` + `install_bundle`) → یک بار صفحه را reload کنید (مرورگر ماژول کلاینتِ هر boot را کش می‌کند).
- هنگام انتشار نسخهٔ تازه `version` در `package.json` را بالا ببرید؛ `install_bundle` برای نصبِ همان نسخهٔ قبلی خطای `already-installed` می‌دهد.
- سازگاری DSH روی نسخهٔ `0.2.1-rc.2` آزموده شده. پلاگین فقط از سطوح پایدار
  استفاده می‌کند: اسلات‌های Client (`conversation.composer.dock` و
  `settings.general.item`)، سرویس locale، و توکن‌های تم.
